# Data Warehouse Project

## Overview

This repository contains the implementation of a Data Warehouse project, including database setup, staging layer design, and raw data ingestion.

## Project Scope

* Repository and project structure setup.
* Database initialization.
* Raw CSV ingestion into staging tables.
* Data validation and quality checks.

## Project Structure

* `docs/` — Project documentation.
* `sql/` — SQL scripts.
* `scripts/` — Data loading and automation scripts.
* `data/` — Local data files; raw datasets may be excluded from Git.

## Workflow

Implementation will proceed task by task, with validation performed after each major step.
